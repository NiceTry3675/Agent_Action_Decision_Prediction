# Sonnet 교차-가문 리레이블 재실험 — 사전 등록 (2026-07-11)

## 배경 / 재심 사유

07-10 "휴먼 시맨틱 리레이블"(248행, `20260710_human_relabel/`)의 어노테이터는
사람이 아니라 **GPT-5.6**이었음이 확인됨 (사용자 공지, 07-11). 이로 인해:

- "어노테이터 간 신뢰도 91.3%"는 독립 검증이 아니라 동일 모델의 편향 반복일
  수 있음 — 원 결론("약클래스 라벨 = 생성기 정책 기록, 의미 계열 종료")의
  주석 축이 무너짐.
- 재구성 검증(225/248행 라벨 = 생성기 실제 행동)은 어노테이터 무관이므로
  **재심 대상이 아님**. 재심 대상은 "그 행동이 요청 의미와 단절"이라는
  의미 판정.
- 원 설계의 추가 결함: (1) 오류-편중 표본만 있고 정답-행 대조군 없음(보고서
  스스로 한계로 명시), (2) 라벨 공간이 weak4+other+underdetermined 6개로
  weak-중심 강제.

## 설계

어노테이터: **claude-sonnet** (GPT-5.6과 이종 가문). 블라인드: 데이터셋 라벨,
모델 예측, 로짓, 층 정보 비노출. 3개 층을 섞어 셔플(seed 43)한 뒤 16행×31
배치로 분할, 배치당 독립 에이전트 1개(상호 참조 불가 = 독립 주석).

| 층 | N | 구성 | 목적 |
|---|---|---|---|
| A | 248 | 원 케이스북 행 전체 (id 동일) | GPT-5.6 판정의 교차-가문 재현 |
| B | 120 | `kd_hcx_m8_screen` fixed-val에서 학생이 **맞힌** weak4 행, 클래스당 30 (seed 42) | 원 실험에 없던 대조군 |
| C | 120 | c=0 중 5모델(M7/M8/v6 OOF + gemma/llama train) 만장일치-대안 5,298행 표본, 공식 라벨 비례 층화 (seed 42) | H1(오라벨) vs H2(정책 확률성) 판별 |

입력: `train.jsonl` 원행의 `current_prompt`/`history`/`session_meta` 전체
(원 실험은 meta를 4필드로 절삭 — 본 재실험은 전체 제공, 프로토콜 편차로 기록).
라벨 공간: **14클래스 전체 + underdetermined**. 필드: `top_label`,
`acceptable_labels`(합리적 에이전트가 취할 수 있는 모든 라벨),
`identifiability`(clear/plausible_multi/underdetermined), `confidence`,
`rationale`(1문장).

## 사전 등록 판정 기준 (결과 확인 전 고정)

층 A는 원 실험과의 비교를 위해 14클래스를 원 6라벨 체계로 사상(weak4 유지,
나머지 실클래스→other, underdetermined 유지)해 채점한다.

- **R1 (교차-가문 재현성)**: A에서 Sonnet vs GPT-5.6 정확 일치율.
  - ≥ 70%: GPT-5.6 판정은 가문 편향이 아님 — 원 결론의 주석 축 복원.
  - ≤ 55%: LLM 리레이블 판정이 가문 의존적 — "의미 계열 종료"의 주석 근거
    기각(재구성 검증만 잔존), 도크트린 격하.
  - 중간: 불일치 행의 구조(클래스·identifiability별)로 부분 판정.
- **R2 (대조군 분리)**: B에서 Sonnet vs 데이터셋 라벨 정확 일치율.
  - ≥ 65% 이고 A의 데이터셋 일치가 원 실험처럼 낮게(≤35%) 재현되면: 불일치는
    오류행 고유 현상 — "오류행 라벨은 의미와 단절" 결론이 대조군 통과로 강화.
  - ≤ 45%: LLM 어노테이터가 이 과제의 라벨 의미론 자체와 전반적으로 어긋남 —
    원 실험의 21%는 해석 불능, 도크트린의 주석 축 전면 기각.
- **R3 (H1 vs H2, 층 C)**: (a) Sonnet top_label = 위원회 대안 비율,
  (b) 공식 라벨 ∈ acceptable_labels 비율, (c) underdetermined/plausible_multi 비율.
  - (a) 높고 (b) 낮음(≤20%): 의미적으로도 대안이 정답 — H1(오라벨) 성분 우세.
  - (b) 높음(≥40%) 또는 (c) 높음(≥40%): 다봉/미결정 — H2(정책 확률성) 우세,
    "완충이 올바른 처치" 해석 유지.
- **운영 결정 연결**: R1·R2가 모두 도크트린 쪽으로 나오면 의미 계열 종료 유지.
  R2가 기각 쪽이면 의미 계열 재개 여부를 별도 결정(자동 재개 아님 — 학습
  개입은 07-09에 이미 실패했으므로 재개하더라도 후처리 경로 우선).

주의: A/C는 오류-편중·만장일치-편중 표본이므로 어떤 수치도 전역 라벨 품질
추정치가 아니다. 최적화 타깃은 어느 경우에도 원 라벨 유지(Public이 생성기
모방을 보상한다는 사실은 이 실험과 독립).
