# Code Submission Competition Guide

This competition is conducted as a "code submission competition" in which participants submit a `submit.zip` file.

Participants must organize and submit `submit.zip` using the structure below.

## Submission File Structure (`submit.zip`)

```text
submit.zip
├── model/        # Directory for storing model weight files
│      └── (e.g., model.pt, etc.)
├── script.py       # Executable code where actual inference is performed
└── requirements.txt   # Required packages and versions
```

`script.py` is executed automatically on the evaluation server after `submit.zip` is submitted.

`requirements.txt` must be installable with the `pip install -r requirements.txt` command and must include all packages required for inference.

The internal structure of `submit.zip` must match exactly. If the structure does not match, an installation error will occur.

## Items Added by the Evaluation Server

When a submission is made, the evaluation server automatically adds the following items to the submitted `submit.zip` file.

```text
submit.zip
├── model/        # Participant-provided
├── script.py       # Participant-provided
├── requirements.txt   # Participant-provided
├── data/         # Test data used for evaluation (directory automatically created)
└── output/submission.csv        # Path where participant inference results are saved (directory automatically created)
```

The `data/` directory contains the competition data, including the actual evaluation data. It is read-only and cannot be written to or modified.

The `output/` directory is where the prediction result file generated by running the participant's `script.py` is saved. The script must be able to create `submission.csv` in this directory.

## Evaluation Server Specifications

- OS: Ubuntu 22.04.5 LTS
- GPU: NVIDIA T4 (VRAM 16 GB)
- CPU: 3 vCPU
- CPU RAM: 12 GB
- Python: 3.11.15
- Internet access: disabled (no external server access or downloads except for package installation)
- CUDA: 12.8

## Preinstalled Packages/Libraries on the Evaluation Server

The packages/libraries below are preinstalled on the evaluation server. For the packages/libraries listed below with specified versions, using a different version may cause installation errors. Therefore, it is recommended to use the packages already installed on the evaluation server whenever possible and not include them in the submitted `requirements.txt`.

If a library installation error occurs, it is treated as an installation error and does not count toward the daily submission limit.
